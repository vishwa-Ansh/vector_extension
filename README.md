# VECTOR-Ø

VECTOR-Ø is an AI-powered coding assistant for Visual Studio Code.

## Features

- AI-powered code analysis
- Error detection
- Code explanation
- Code improvement suggestions
- Project-level code analysis
- Context-aware assistance
- VS Code integrated chat

## How It Works

VECTOR-Ø analyzes your code and provides actionable feedback directly inside VS Code.

## Installation

1. Open VS Code.
2. Open Extensions.
3. Search for VECTOR-Ø.
4. Click Install.

## Usage

Open the VECTOR-Ø panel from the VS Code Activity Bar.

Ask a question or select code to analyze it.

## Requirements

- Visual Studio Code
- Internet connection
- VECTOR-Ø backend/API

## Configuration

Configure VECTOR-Ø from VS Code Settings.

## Privacy

VECTOR-Ø processes code according to its configured backend and AI provider.
